# Rules

> 이 프로젝트의 규칙과 컨벤션. 모든 sub-agent가 반드시 따라야 함.

## G-01: 코드 주석은 영어만 사용 (MANDATORY)

**규칙:** 모든 코드 주석(`//`, `/* */`, `///`)은 영어로 작성. 한글 주석 금지.
**이유:** 소스 파일 내 한글은 인코딩 문제 및 빌드 오류를 유발할 수 있음.
**적용 시점:** 코드 작성 또는 수정 시 항상. UI 텍스트(사용자에게 보이는 문자열)는 한국어 유지.

## P-01: 연산 장치는 하나의 설정이 AI와 보간 경로를 함께 제어한다

**규칙:** `aiDevice` ('cpu' 기본, 'gpu')가 AI 세션(DirectML/CPU)과 보간 경로(WebGL/JS)를 모두 결정한다. 전환은 앱 재시작 없이 즉시 적용한다. NIS는 GPU 전용(CPU에서는 목록에서 비활성, 저장된 NIS는 Lanczos3로 대체).
**이유:** 사용자 결정("CPU를 결정하면 모든 모델이 CPU를 사용"). 코드 리뷰의 "분리" 제안은 의도적으로 채택하지 않음.
**적용 시점:** 장치/보간 설정을 건드릴 때. 분리하려면 먼저 사용자에게 확인.

## P-02: 원본 비율 유지, 선택 밖 화면 금지

**규칙:** 결과 화면은 항상 선택 영역의 비율로 그리고(letterbox), 선택 밖 화면에는 접근할 수 없어야 한다(캡처 시 선택 영역만 보관).
**이유:** 멀티 패널에서 찌그러짐 방지, 요구사항("선택한 부분만 가지고 계산").
**적용 시점:** 결과 창의 view/crop 로직 수정 시.

## P-03: 사용자 대면 문구

**규칙:** 메뉴는 아이콘 위주, 한글 설명문은 넣지 않는다. 설정은 짧은 라벨만. 설정 창은 독립 창.
**이유:** 사용자 요청.
**적용 시점:** UI 추가/수정 시.

## P-04: 배포물

**규칙:** 배포는 `npm run dist`(폴더형 zip, `asar:false`). `release/`, `store/`, `tools/`는 git에 넣지 않는다. AI 모델(`models/*.onnx`: general-x4v3 4.9 MB, NomosUni SPAN 1.6 MB, x4plus 64 MB)은 git에 포함하고 릴리스 zip에도 포함된다.
**이유:** 저장소만 받아도 AI가 동작하도록(사용자 결정). 100 MB 제한 이내이므로 LFS 불필요, 더 큰 모델을 추가하면 LFS 검토.
**적용 시점:** 릴리스 시.

## P-05: AI 모델 선택

**규칙:** 기본 AI는 `realesr-general-x4v3`(id `realesrgan`). `4xNomosUni SPAN`은 가장 작고 빠른 모델, `x4plus`는 목록에 남기되 "그림 위주, 글씨 깨짐, CPU 느림". 새 모델은 x4 ONNX(`input` 1x3xHxW, 0..1)만 `AI_MODELS`에 추가하면 워커가 그대로 쓴다.
**이유:** 글씨와 그림을 모두 잘 확대해야 하고(사용자 판단: x4plus는 글씨가 깨지고 느림), 회사에서 쓰던 모델이 general-x4v3. OmniSR 4x DF2K는 검토 후 제외(글씨가 가늘어지고 그래프선이 끊김, DirectML 실행 실패).
**적용 시점:** AI 모델을 추가/교체할 때. 라이선스(NC 모델 제외, CC-BY는 README 크레딧)를 확인.
